What the published data actually means

Verified links ≠ independent servers

Many working links may resolve to the same IP. The repository reports links and real server counts separately.

Measured speed ≠ local speed

Latency and uptime are historical measurements from the designated test runner, not the visitor’s browser or ISP.

Transparency over guarantees

The public README documents the test method, the data format and important limitations. There is no promise that each proxy works everywhere.

How to add a proxy to Telegram

Android and iPhone

Tap any Connect link in the explorer, or any line of top100.txt, and Telegram asks to connect. To add one by hand: Settings → Data and Storage → Proxy → Add Proxy → MTProto, then enter the server, port and secret.

Telegram Desktop

Click a Connect link, or open Settings → Advanced → Connection type → Use custom proxy → Add proxy → MTProto and enter the same three values.

If a proxy does not connect

Try another one. Tests run from the runner location, so a proxy that passed there can still be blocked on your network. Telegram keeps message content encrypted, but the proxy operator can see your IP address.

Free Telegram proxies: how this project works

Answers grounded in the public repository, its verification methodology and its documented limitations.

What is Free-Telegram-Proxy?

It is an open-source collection of Telegram MTProto proxy links maintained by 0xRadikal under the Raydikalx brand. It groups results by verification and selection criteria rather than promising universal access.

How does it verify a Telegram proxy?

The project tests whether a proxy relays an MTProto request to a real Telegram datacenter and returns the expected response containing the test nonce. Verified proxies must pass all three rounds. A successful TCP connection alone is not enough.

What is the difference between verified and resilient lists?

Verified includes links that pass every end-to-end round, which may contain multiple aliases for the same server. Resilient keeps at most one link per server IP so repeated domains do not inflate apparent server diversity.

How are fast and stable proxies selected?

Fast is the fastest quarter of the resilient list by median round-trip time measured from the test runner. Stable requires at least 90% success over the recent history, with a minimum of 12 checks.

Do verified proxies work from every country or ISP?

No. Tests are carried out from the indicated runner location. Firewalls and censorship differ by network, and runner-side measurements cannot guarantee reachability from your own provider.

Can a Telegram proxy see my messages or IP address?

The proxy operator can see your IP address and connection metadata. Telegram protects message content using its own MTProto encryption; this project does not certify operators or post-login sponsored channels.

Where can I get the full proxy data and source code?

The GitHub repository publishes machine-readable index.json, tier-specific proxies.json files, direct Telegram links and selection criteria. You can inspect the source, issue history and methodology independently.
