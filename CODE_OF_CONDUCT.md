# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, discuss evidence rather than people, and keep issue threads on topic. Harassment, doxxing, and posting other people's private data are not tolerated.

**Reporting:** use GitHub's private vulnerability reporting (Security → *Report a vulnerability*) for anything sensitive, or contact the maintainer via [@Raydikalx](https://t.me/Raydikalx). Reports are handled confidentially.

Maintainers may remove comments, issues or contributions that violate this code, and may block repeat offenders.
